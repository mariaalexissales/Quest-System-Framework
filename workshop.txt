title=Quest System Framework
description=[h1]Quest System Framework[/h1]
description=[h2]Made for MP Servers in mind :D[/h2]
description=[b]Quests your admins write in a text (.json) file. No Lua, no repacking, no restart.[/b]
description=
description=Ever wanted to actually give your players something to do? Maybe even… reward them for it? That’s this.
description=
description=Drop a .json into [b]Zomboid/Lua/QuestFramework/[/b] and it’s a quest. Hit Reload in the panel and it’s live. Nobody logs off.
description=
description=[code][
description=  {
description=    "key": "intro_supplies",
description=    "title": "Something To Build With",
description=    "description": "You won’t last the week with what’s in your pockets. <LINE> Bring me the basics and we’ll talk about the work that pays.",
description=    "objectives": [
description=      { "type": "collect", "item": "Base.Nails", "count": 10 },
description=      { "type": "collect", "item": "Base.Plank", "count": 4 }
description=    ],
description=    "rewards": {
description=      "items": [ { "item": "Base.Hammer", "count": 1 } ]
description=    }
description=  }
description=][/code]
description=
description=That’s a working quest. Load the game, press [b]J[/b], and it’s sitting in Available.
description=
description=[hr][/hr]
description=[h2]What You Can Write[/h2]
description=[b]Go kill things somewhere:[/b] 25 zombies in Louisville, 40 in Ekron, 15 in the Muldraugh trainyard. It counts where the zombie dropped, so no cheesing it from the next town over.
description=
description=[b]Go fetch things:[/b] 20 nails, 4 planks, whatever you like. It reads inside bags, because that’s where people keep things, and it takes them off you on turn-in unless you say otherwise.
description=
description=[b]Locations:[/b] Every region the game already names, plus Ekron, Fallas Lake, Brandenburg, Echo Creek and Irvington, which it doesn’t. Named buildings work too - Crossroads Mall, the Sunstar, Knox Bank. Or just draw a box on the map and give it coordinates.
description=
description=[b]Teleport:[/b] Give a quest a coordinate and players get a Teleport button once they’ve accepted it, with a confirm prompt before it moves them. Set a cooldown if you’d rather it wasn’t a free ride home and back, or leave it off.
description=
description=[b]Prerequisites:[/b] Gate a quest behind other quests, skill levels, kill counts or days survived. Locked ones sit there greyed out with the reason written on them, so people know what they’re chasing instead of wondering why the list is short.
description=
description=[b]Rewards:[/b] Items and XP, straight to the player! Or put a few options on the table and let them pick one when they turn it in.
description=
description=[b]Repeatables:[/b] Comes with cooldowns and a cap on how many times.
description=
description=[hr][/hr]
description=[h2]The Panel[/h2]
description=Three tabs: [b]In Progress[/b], [b]Available[/b], [b]Completed[/b]. Click a quest and you get the description, every objective with a tick or a cross beside it, a live counter, and what it pays. Accept, turn in, or bin it off. Sidebar button on the end of the map fly-out, or press [b]J[/b].
description=
description=[hr][/hr]
description=[h2]For Servers[/h2]
description=Everything lives server-side. Just drop the .json in the intended path. The first time the server starts with no quests, it makes the folder for you with a starter quest in it, so you know exactly where to look. You don’t gotta restart the server [b]at all.[/b] Reload pushes edits to everyone live, and only admins get the button. I know this is the 2nd time I put out these instructions, but if you need further help, please refer to the discussion below on how to set this up  ^^
description=
description=Don’t worry, I also thought about error handling. So if you mess up and a quest doesn’t show up properly, you know why and the server keeps running. Write a prereq loop and it’ll spot that too. I tried to think of as many edge cases as possible (because I’m the type of person to make these mistakes almost always…)
description=
description=Want to test this locally before putting this on the server? The same steps work in singleplayer :D
description=
