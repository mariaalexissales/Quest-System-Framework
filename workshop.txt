title=Quest System Framework
description=[h1]Quest System Framework[/h1]
description=[h2]Ready for B42.20+!![/h2]
description=[b]Quests your admins write in a text file. No Lua, no repacking, no restart.[/b]
description=
description=Ever wanted to actually give your players something to do? Not a rules channel nobody reads, not a Discord post about the new town, an actual job with an actual payout that the server checks and pays out itself? That’s this.
description=
description=Drop a .json into [b]Zomboid/Lua/QuestFramework/[/b] and it’s a quest. Hit Reload in the panel and it’s live. Nobody logs off.
description=
description=[code]
description=[
description=  {
description=    "key": "mall_run",
description=    "title": "The Mall Run",
description=    "location": "CrossRoadsMall",
description=    "objectives": [ { "type": "kill", "count": 30 } ],
description=    "rewards": { "items": [ { "item": "Base.Money", "count": 200 } ] }
description=  }
description=]
description=[/code]
description=
description=That’s the whole thing. Kill 30 at Crossroads, get 200 bucks.
description=
description=[hr][/hr]
description=[h2]What You Can Write[/h2]
description=[b]Go kill things somewhere.[/b] 25 zombies in Louisville, 40 in Ekron, 15 in the Muldraugh trainyard. It counts where the zombie dropped, so no cheesing it from the next town over.
description=
description=[b]Go fetch things.[/b] 20 nails, 4 planks, whatever you like. It reads inside bags, because that’s where people keep things, and it takes them off you on turn-in unless you say otherwise.
description=
description=[b]Locations.[/b] Every region the game already names, plus Ekron, Fallas Lake, Brandenburg, Echo Creek and Irvington, which it doesn’t. Named buildings work too - Crossroads Mall, the Sunstar, Knox Bank. Or just draw a box on the map and give it coordinates.
description=
description=[b]Prerequisites.[/b] Gate a quest behind other quests, skill levels, kill counts or days survived. Locked ones sit there greyed out with the reason written on them, so people know what they’re chasing instead of wondering why the list is short.
description=
description=[b]Rewards.[/b] Items and XP, straight into the inventory.
description=
description=[b]Repeatables[/b], with cooldowns and a cap on how many times.
description=
description=[hr][/hr]
description=[h2]The Panel[/h2]
description=Three tabs. [b]In Progress[/b], [b]Available[/b], [b]Completed[/b]. Click a quest and you get the description, every objective with a tick or a cross beside it, a live counter, and what it pays. Accept, turn in, or bin it off. Sidebar button next to your crafting one, or press J.
description=
description=[hr][/hr]
description=[h2]For Servers[/h2]
description=The server owns the lot. It reads the files, it keeps everyone’s progress, and it checks every accept and every turn-in itself - your players never touch a quest file and can’t hand themselves a reward. Reload pushes edits to everyone live, and only admins get the button.
description=
description=Fat-finger a quest file and you lose that one quest and get a line in the log telling you which and why. The server keeps running. Write a prereq loop and it’ll spot that too, which is the sort of thing that would otherwise have you scratching your head for a fortnight wondering why nobody can pick up chapter two.
description=
description=Works in singleplayer as well, same code path, so you can write your quests and test them without standing up a server.
description=
description=[hr][/hr]
